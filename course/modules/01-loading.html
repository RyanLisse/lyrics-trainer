Cutting the Script into Cue Cards

How a plain text file becomes the list of lines the app steps through

What the app actually does

Lyrics Trainer shows you a song or poem one line at a time, so you can memorise it the way an actor learns a part. You press Next, swipe, or let it auto-advance. Behind that simple screen sits a small Progressive Web App (PWA) written in TypeScript.

src/ The code you edit
lyrics-core.ts Pure logic: splitting text, counting, validating. No screen access at all
script.ts The wiring: buttons, keys, rendering, saving
public/ What the browser receives
index.html The page skeleton: lyric box, buttons, progress bar
lyrics/ sonnet_18.txt and casey_at_the_bat.txt
service-worker.js Offline support (module 6)
tests/ Vitest suites that prove it all works

The metaphor: a stagehand with scissors

Imagine a stagehand given a whole script on one long sheet. Before the show, they cut it into cue cards, one line each, and throw away the blank strips. The app does exactly that the moment it opens.

The scissors, in code

This is the whole cutting step, from src/lyrics-core.ts. It is a pure function: text goes in, a list comes out, nothing else is touched.

src/lyrics-core.ts 
/** Split raw text into trimmed, non-empty lines. Handles \n and \r\n. */
export function processLyricsText(text: string): string[] {
    return text
        .split(/\r?\n/)
        .map(line => line.trim())
        .filter(line => line.length > 0);
}
PLAIN ENGLISH

A note to humans: this works for files from Mac/Linux (\n) and from Windows (\r\n).

Define a tool called processLyricsText. It takes text and promises to hand back a list of strings.

Start with the raw text...

...cut it at every line break, with or without the Windows carriage return...

...shave the spaces off both ends of every piece...

...and keep only pieces that still have at least one character.

Done: the stack of cue cards goes back to whoever asked.

💡
Why the logic lives in its own file

Keeping DOM-free logic in lyrics-core.ts means tests can call it directly with a string. Tell an AI "put this in the pure core and unit-test it" and you get code that is easy to check.

The fetch, and its odd little timestamp
